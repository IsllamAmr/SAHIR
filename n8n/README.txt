n8n for Saher (local only)

Start:  double-click start-n8n.bat, wait ~2 minutes, then open http://127.0.0.1:5678
Stop:   close the n8n window, or double-click stop-n8n.bat

Program:  app\   (n8n 2.43.7 from npm, Node 24)
Data:     data\.n8n\  (workflows, credentials, database.sqlite) - back this folder up
Listens on 127.0.0.1:5678 only. Telemetry, templates and version checks are off.
Does not start with Windows.
